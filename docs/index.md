## 🎯 Objetivos do Projeto

1. Demonstrar o ciclo completo de desenvolvimento de **sistemas agênticos com Google Cloud**.
2. Integrar memória contextual de longo prazo com o **Vertex AI Memory Bank**.
3. Persistir dados estruturados no **Google Cloud Firestore**.
4. Gerar artefatos visuais com o modelo **Gemini Image (`gemini-3.1-flash-lite-image`)** e publicá-los no **Google Cloud Storage**.
5. Oferecer uma experiência de interface rica com **A2UI v0.8** (cards, tabelas e imagens).
6. Disponibilizar frontend web moderno conteinerizado no **Google Cloud Run**.
